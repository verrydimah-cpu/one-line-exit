One single-line resignation letter: "Dear Boss, I hereby resign to sell sunscreen in Alaska; the sales targets there still sound more achievable than yours." A salesperson quits for the most hopeless sales job imaginable — sunscreen in Alaska — and the joke turns on the comparison: even those targets sound more achievable than the ones at the job being left. The program in `main.ts` (Node 22, standard library only) writes that single line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
